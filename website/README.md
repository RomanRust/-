# next — подготовка к SAT и IELTS

Одностраничный сайт на HTML, CSS и JavaScript. Светлый фон с тонкой сеткой, оранжевый акцент, локальный шрифт Golos Text с кириллицей. Без сборки и сторонних JS-библиотек.

## Запуск

Дважды щёлкните файл **«Открыть сайт.cmd»** в этой папке. Он запустит локальный сервер и откроет сайт в браузере. Повторный запуск использует уже работающий сервер. Сервер остаётся работать после закрытия окна запуска; после перезагрузки компьютера запустите файл снова.

Либо из папки `website` выполните:

```powershell
node launch.js
```

Откройте http://127.0.0.1:4173. Установка зависимостей не нужна. Для другого порта задайте `$env:PORT = '4174'` перед запуском.

Для запуска в терминале с остановкой по Ctrl+C используйте `node server.js`.

Можно открыть `index.html` двойным щелчком: все стили, шрифты и интерактивные элементы работают без подключения к интернету.

## Форма заявки

- Проверяет имя, email или Telegram, выбранное направление и согласие на связь.
- При запуске через `node server.js` отправляет данные в локальный обработчик и сохраняет их в `data/applications.jsonl`. Одна строка — одна заявка. Эта папка не раздаётся веб-сервером.
- При открытии через `file://` сохраняет заявки только в localStorage текущего браузера, ключ `next-local-applications`. Интерфейс явно сообщает об этом.
- Подтверждение появляется только после успешного сохранения. При ошибке введённые данные остаются в форме.
- Форма не подключена к почте, Telegram или CRM и не рассылает уведомления. Для публичного запуска нужен хостинг с серверной обработкой и подключение нужного канала получения заявок.
- Сервер слушает только `127.0.0.1`. Он предназначен для локального запуска.

## Содержимое

- `index.html` — контент и доступная разметка.
- `styles.css` — адаптивный дизайн для компьютера, планшета и телефона.
- `script.js` — переключение SAT/IELTS, мобильное меню, выбор программы и форма.
- `server.js` — локальная раздача сайта и сохранение заявок на Node.js.
- `assets/` — локальные шрифты, лицензия и favicon.

Оффер: пятимесячная онлайн-подготовка, бесплатная диагностика и персональный план. Next — рабочее название концепции. Баллы в карточке маршрута обозначают пример цели, а не обещание результата. В макете нет вымышленных отзывов, партнёров, статистики, цен или контактных данных.

Перед коммерческим запуском подставьте реальное название школы, стоимость и условия курса, контакты и правила обработки заявок.
